Предупреждение Lint в обоих приложениях — рекомендация явно добавить старый `fullBackupContent` для Android до 12 при наличии `dataExtractionRules`. `allowBackup=false` уже установлен; это не ошибка сборки. Вывод сохранён без скрытия предупреждений.

Тесты проверяют: сериализацию кадра, ограничение размера, обрыв данных, преобразование координат фокуса с учётом пропорций, ориентацию/округление отсчёта, журнал повторов команд и отклонение NaN. Они не проверяют работу реального HAL камеры, MediaRecorder, Google Play services или UI.

В ходе работы исправлены обнаруженные ошибки/риски: проверка разрешения перед открытием камеры, вызовы API 30 на Android 10, повторные команды, зависший поток, несогласованность заголовка при смене качества, выключение экранной подсветки при закрытии окна. Промежуточный сбой инкрементального DEX после изменения ресурсов устранён чистой сборкой; итоговая сборка успешна.
