# WristLens 1.8.0 — установка и использование

Обновите **оба устройства**: `WristLens-phone-1.8.0-release.apk` на телефоне и `WristLens-wear-1.8.0-release.apk` на часах. Удалять прежнюю версию не нужно: идентификатор и сертификат подписи сохранены. Это release APK с отключённой отладкой, без публикации в Google Play.

## Установка

На телефоне откройте APK и подтвердите установку. Через ADB:

```sh
adb -s PHONE_SERIAL install -r WristLens-phone-1.8.0-release.apk
```

На часах включите параметры разработчика и беспроводную отладку. Компьютер и часы подключите к Wi-Fi. Порт сопряжения отличается от порта подключения:

```sh
adb pair WATCH_IP:PAIRING_PORT
adb connect WATCH_IP:CONNECTION_PORT
adb -s WATCH_IP:CONNECTION_PORT install -r WristLens-wear-1.8.0-release.apk
```

Подставьте данные устройств. Если ADB уже сопряжён, повторное `pair` не требуется. После установки отладку можно отключить. [Официальная инструкция Wear OS](https://developer.android.com/training/wearables/get-started/debug-wifi).

## Запуск и язык

Устройства должны быть сопряжены; нужны Google Play services. Один раз откройте приложение телефона и выдайте разрешение камеры. Микрофон нужен для записи звука. Затем открытие приложения часов автоматически запрашивает запуск телефонной сессии. Кнопка телефона повторяет запрос. Android может потребовать разблокировать телефон; приложение не обходит разрешения и системную блокировку. После принудительной остановки откройте телефонное приложение вручную.

При основном системном языке ru интерфейс русский, при другом — английский. Язык каждого устройства выбирается отдельно. Меню, инструкции, настройки и сообщения приложения переведены; диагностические коды производителя могут оставаться техническими.

## Управление

| Элемент | Действие |
|---|---|
| Верхняя прозрачная дуга | Режим, время/длительность, масштаб |
| Молния | Вспышка; при видео — выкл./постоянная |
| Таймер | 0 → 2 → 3 → 5 → 10 с для выбранного режима; до 60 с через параметры |
| Стрелки | Следующая камера до записи |
| Слева внизу | Фото/видео; при записи — пауза/продолжение |
| Центральная кнопка | Фото или запуск видео; при записи — фото; при таймере — отмена |
| Удержание фото | Серия после 350 мс; отпустите для остановки |
| Справа внизу | Меню; при записи — стоп; удержание стоп открывает меню |
| Одиночное касание изображения | Точечный фокус/экспозамер при поддержке, с короткой задержкой для отличия от двойного касания |
| Щипок двумя пальцами на экране | Уменьшить/увеличить отображение потока на часах |
| Перетаскивание изображения | Сместить видимую область кадра |
| Двойное касание изображения вне кнопок | Вернуть исходный размер и центрирование |
| Вращательный ввод | Масштаб, если часы передают rotary-события |

По умолчанию поток заполняет круг с обрезкой краёв, без искажения пропорций. Щипком его можно уменьшить до полного кадра с чёрными полями; даже углы прямоугольника помещаются внутри круга. Разведение пальцев увеличивает изображение, перетаскивание сдвигает видимую область, двойное касание вне кнопок возвращает исходное заполнение экрана и центрирование. Это только отображение на часах: размеры потока, файлы, зум и запись камеры не меняются. Масштаб камеры по-прежнему регулируется безелем и в параметрах камеры. Часы в меню нарисованы по дуге поверх содержимого, без подложки и отдельной строки. Изменение параметра оставляет страницу настроек открытой и сохраняет прокрутку.

Серия: максимум и значение по умолчанию **50 кадров**, интервал по умолчанию **200 мс после сохранения предыдущего кадра**. В меню также доступны 250, 500, 1000, 2000 и 5000 мс. Это не гарантия 5 кадров/с: экспозиция, размер и знак влияют на скорость. Общий предел — 60 секунд после первого кадра. При отпускании новые кадры прекращаются; уже снимаемый кадр может завершиться. Потеря сигнала удержания останавливает серию примерно через 1,2 с. Таймер перед серией отсчитывается один раз, кнопку нужно держать. При видео доступны одиночные снимки.

## Галерея и отправка

В меню откройте «Галерея» / **Gallery**. Есть список и плитка, выбранный вид запоминается. Удерживайте файл, затем отмечайте остальные касанием. Доступны пакетное удаление, скачивание и отправка. Удаление требует подтверждения; после него обновляются список и миниатюра меню.

«Поделиться на телефоне» / **Share on phone** открывает системное меню отправки на телефоне. Получателя и отправку подтверждает пользователь. Скачанными копиями можно поделиться через установленное приложение часов; при отсутствии такого приложения используйте телефон.

Нажатие на файл открывает предпросмотр. Видео воспроизводится при поддержке кодека часами. Можно открыть оригинал на телефоне, удалить или скачать на часы. Проверяется SHA-256; копия сохраняется в выбранную папку часов (по умолчанию `DCIM/Camera`). Повторная ручная и автоматическая передача одного файла с одинаковой папкой и качеством не создаёт дубликат. При смене папки или качества можно скачать новую копию; прежняя остаётся. Закрытие карточки или выход из приложения часов не отменяет передачу. Отмена доступна в уведомлении и карточке файла. Автоматическая очередь использует те же статусы.

Удаление оригинала с телефона и копии с часов — отдельные действия. «Сохранённое на часах» доступно без телефона. Галерея показывает файлы приложения.

## Автосохранение на часы

**Меню → Файлы и сохранение → На часах → Автоматически сохранять фото и видео** / **Files and saving → On the watch → Automatically save photos and videos**. По умолчанию выключено. Для включения нужен подключённый телефон.

Копируются новые завершённые фото и видео с выбранным качеством. По умолчанию передаются оригиналы. Старая галерея при включении не переносится. Ролик, завершившийся после фотографий во время записи, тоже попадёт в очередь. Передача последовательная, продолжается после выхода с часов и повторяется при восстановлении связи. Android может откладывать фоновую работу. Есть статус и кнопка повтора. Отключение отменяет очередь, уже сохранённые копии остаются.

Лимит — 4 ГБ на файл; слишком большой файл пропускается с сообщением. При нехватке памяти очередь ждёт освобождения места. Прерванный файл передаётся заново, частичная копия не публикуется. Большие видео расходуют заряд и память.

## Водяной знак

В **«Параметры камеры» / Camera settings** включите **«Водяной знак на фото и видео»** до съёмки. Выберите угол, белый/чёрный цвет, размер, дату и/или время. Шрифт системный, время и часовой пояс берутся с телефона.

Знак встраивается в пиксели сохранённых фото и видео. Превью часов может оставаться без знака — проверяйте сам файл. JPEG без знака сохраняется без перекодирования. Со знаком учитывается EXIF-поворот, JPEG кодируется с качеством 95; PNG/WebP тоже содержат знак. Большие фото требуют дополнительной памяти.

Видео проходит GPU-композицию перед кодировщиком. Учитывается поворот видео. В режиме HS знак недоступен: выберите обычный режим или выключите его. При ошибке обработки показывается сообщение; запись без единого обработанного кадра не публикуется как успешная. Счётчик есть в диагностике `watermarkFrames`.

## Меню, безель и галерея

Прямоугольного ограничения прокрутки больше нет. Меню занимает весь экран, у содержимого оставлены боковые, верхний и нижний отступы, заголовки центрированы. У края круга часть прокручиваемого содержимого естественно уходит за экран; прокрутите её к центру для чтения. Время находится на прозрачной верхней дуге и скрывается при прокрутке, чтобы не перекрывать текст. Справа появляется дуга положения только во время прокрутки. Её длина зависит от видимой доли списка, положение — от прокрутки. Через 0,9 секунды после остановки она плавно скрывается. На страницах без прокрутки дуги нет.

Вращение поддерживаемого безеля/колёсика прокручивает меню. На часах без такого системного ввода ведите пальцем по правому краю экрана: встроенная круговая сенсорная зона выполняет ту же функцию. В открытом слайдере масштаба или ручного фокуса вращение меняет значение небольшими шагами около 0,05. Кнопка «Применить» отправляет значение телефону. Вертикальная прокрутка пальцем остаётся доступной.

Системная кнопка/жест «Назад», кнопка внутри страницы и свайп вправо от левого края закрывают текущий подпункт, возвращая к предыдущему меню. Изменение настройки внутри меню подтверждается сообщением **«Сохранено»** после успешного ответа. Быстрые действия иконками и изменение масштаба безелем на главном экране камеры этого сообщения не показывают; ошибки остаются видимыми. Ошибки не подтверждаются как успешное сохранение.

На главном экране короткое касание молнии, таймера и смены камеры сохраняет прежнее быстрое действие. **Удержание** открывает соответствующие подробные настройки.

В режиме «Список» миниатюра слева, имя и свойства справа; «Плитка» — два столбца. Счётчик «Файлов» относится ко всей открытой галерее WristLens на телефоне или к локальным копиям на часах. Длинное имя сокращается в строке, полностью доступно в карточке.

Удерживайте файл, затем нажмите **«Выделить всё»**. На телефоне это включает файлы за пределами загруженной страницы. **«Снять выделение»** отменяет выбор. Удаление требует подтверждения и выполняется порциями по 50, выбор от этого не ограничивается 50 файлами. При ошибке после частичного удаления галерея обновляется. Отправка через системное меню поддерживает до 500 файлов за один раз; приложение-получатель может иметь собственные ограничения.

## Подгонка потока на часах (1.8)

- **Свести два пальца на экране:** уменьшить изображение вплоть до полного вписывания кадра в круг с чёрными полями. Пропорции сохраняются, все четыре угла видны.
- **Развести два пальца:** увеличить изображение до 3× относительно стандартного заполнения экрана.
- **Перетащить изображение:** переместить видимую область. Начинайте одним пальцем вне кнопок; во время щипка можно перемещать и оба пальца. На границе сдвиг останавливается. Если кадр уже меньше экрана по одной из осей, по этой оси он остаётся по центру.
- **Дважды коснуться изображения вне кнопок:** сбросить размер и сдвиг к исходному заполнению экрана.

Положение сохраняется между поступающими кадрами и при открытии меню. При смене ориентации, зеркальности или пропорций кадра включается исходный вид. После нового запуска приложения вид также стандартный. Эти действия не вызывают сообщения «Сохранено». Кнопки съёмки и строка состояния остаются на своих местах.

Одиночное касание фокусирует выбранную точку уже с учётом увеличения и сдвига; касания чёрных полей игнорируются. Для отличия от двойного касания фокусировка срабатывает после короткой системной задержки. Щипок отменяет ожидающее нажатие кнопки и удержание серии, если начинается поверх них. Уже сделанные кадры серии сохраняются.

Проверка на часах: уменьшите изображение до видимых углов кадра, увеличьте, сдвиньте в обе стороны, дважды коснитесь центра. Повторите во время записи: ролик должен продолжаться без изменения реального зума, а кнопки — оставаться на месте.

## Что означают настройки предпросмотра

| Режим | Максимальная целевая частота | Картинка на часах |
|---|---:|---|
| Экономия | Около 3 кадров/с | До 320 px и границ экрана, сильнее JPEG-сжатие, меньше трафика |
| Плавность — по умолчанию | Около 15 кадров/с | В пределах разрешения экрана, обычное JPEG-сжатие |
| Детализация | Около 8 кадров/с | В пределах разрешения экрана, меньше JPEG-сжатие |

Это целевые верхние частоты, не гарантированная скорость: она зависит от соединения, телефона и нагрузки. В 1.3 у режима «Детализация» действительно уменьшено сжатие: качество JPEG 85 вместо 60 у «Плавности»; у «Экономии» — 40. Выбранный профиль сохраняется между сессиями.

Эти настройки не меняют разрешение обычного фото и параметры сохраняемого видео. Исключение — снимок **из потока** во время записи (`snapshotMode: preview`): его качество зависит от предпросмотра. Размер видео и FPS записываемого файла выбираются отдельно в параметрах камеры.

## Меню, экран, вибрация и звуки

«Настройки часов» и отдельные «Настройки съёмки» убраны. В меню часов остались «Галерея», «Параметры камеры», «Файлы и сохранение», переключатели вибрации и звуков съёмки, «Инструкция» и одна кнопка подключения/отключения по текущему состоянию. Внизу меню отображаются название и версия: **WristLens · 1.8.0**, без кредитов.

«Параметры камеры» объединяет размеры кадра, фокус, зум, таймеры, серию, предпросмотр, работу в фоне и водяной знак. «Файлы и сохранение» содержит два блока на одной странице: настройки оригиналов на телефоне и копий на часах. Пояснения из настроек перенесены во встроенную инструкцию.

**Меню → Вибрация действий**. По умолчанию включена. Переключатель управляет откликом кнопок, переключателей, безеля, подтверждений съёмки и длительных нажатий приложения; системные уведомления и клавиатура имеют собственные настройки.

Кнопки меню и переключатели дают короткий тактильный отклик. Безель сопровождается импульсами при реальной прокрутке или изменении значения слайдера; на упоре, короткой странице без прокрутки и при выключенной вибрации импульсов нет. Сенсорный край и аппаратный вращательный ввод используют одну логику. Учитывается и системная настройка тактильного отклика.

**Меню → Звуки съёмки / Capture sounds**. По умолчанию включены, независимо от вибрации. Звуки воспроизводят часы: одиночное фото — щелчок затвора, серия — более короткие щелчки, видео — разные сигналы начала, паузы, продолжения и завершения. Учитываются системные настройки громкости и звука часов. Переключатель не меняет настройку записи микрофона телефона.

Звук и вибрация следуют подтверждённому действию камеры, а не только нажатию кнопки. Каждый успешно сохранённый кадр серии вызывает короткий виброотклик, если включена «Вибрация действий». Одиночные фото и серия сопровождаются короткой анимацией диафрагмы на предпросмотре; кнопки остаются видимыми и доступными. Анимация не зависит от переключателей звука и вибрации.

После возврата из фона или переподключения прошлые события не воспроизводятся. Повторные сообщения телефона не создают повторный отклик. При скоплении событий из-за медленной связи часы воспроизводят только последний свежий сигнал. Поэтому отклик может отставать от затвора на время сохранения и передачи. В фоне часы не озвучивают съёмку.

При отмене запущенного таймера появляется **«Таймер отменён»** — без упоминания серии.

Экран остаётся включённым только на главном экране камеры. Открытое меню, галерея и вложенные настройки не блокируют обычное системное выключение экрана. Обратный отсчёт и запись следуют настройке «Работа в фоне», если часы засыпают.

Распознавание щипка пальцами в воздухе, обучение и пункт меню жестов удалены. В версии 1.8 добавлены сенсорные жесты именно на экране для подгонки предпросмотра. Свайпы навигации, удержание фото и управление по краю экрана сохранены.

## Папка и сжатие копий на часах

**Меню → Файлы и сохранение → На часах**: «Папка на часах», «Сжатие фото», «Сжатие видео». Эти параметры действуют на ручное скачивание из галереи и автоматическую очередь, даже если автосохранение выключено.

Папки: `DCIM/Camera`, `DCIM/WristLens` или собственная вложенная папка внутри `DCIM`, например `DCIM/WristLens/Поездки`. Папка создаётся при первом сохранении. Готовые файлы автоматически не перемещаются. Размер и имя берутся из передаваемой копии; уменьшенные файлы имеют суффикс `_balanced` или `_compact`.

| Файлы | Оригинал — по умолчанию | Среднее сжатие | Сильное сжатие |
|---|---|---|---|
| Фото | Без перекодирования | JPEG 85%, длинная сторона до 1920 px | JPEG 70%, до 1280 px |
| Видео | Без перекодирования | MP4 H.264/AAC, до 1280 px, целевой битрейт 2 Мбит/с | MP4 H.264/AAC, до 854 px, целевой битрейт 1 Мбит/с |

Уменьшенные видео — до 30 кадров/с, звук AAC с целевым битрейтом 96 кбит/с, если звук был в исходнике. Пропорции и поворот сохраняются, изображения не увеличиваются. Фактический битрейт зависит от кодировщика телефона; уменьшение размера в байтах не гарантируется для уже сильно сжатого исходника. Встроенный водяной знак остаётся частью изображения. Сжатые копии могут потерять дополнительные метаданные; «Оригинал» сохраняет исходные байты целиком.

Сжатие выполняется **на телефоне до передачи**, оригиналы не меняются. Во время обработки показывается «Подготовка скачивания…», затем прогресс передачи. Длинные видео требуют времени и свободной памяти телефона для временной копии. При ошибке кодировщика отображается сообщение; можно повторить с исходным качеством. Временный файл удаляется после передачи, незавершённая копия на часах не публикуется.

Настройки фиксируются для каждого файла в момент начала запроса. Изменение параметров во время скачивания применяется к следующему файлу. После успеха отображается **«Скачано на часы»** или **«Скачано: N»**; после удаления — **«Удалено»** или **«Удалено: N»**. Ошибка не показывается как успешное завершение.

## Автоотключение

Если приложение часов ушло в фон и съёмка не выполняется, сессия камеры завершается после **60 секунд непрерывного простоя**. Это освобождает камеру телефона и снимает удержание процессора после остановки сервиса. Открытое меню остаётся активным приложением; простой внутри меню не считается уходом в фон до системного выключения экрана или закрытия приложения.

Запись, в том числе на паузе, активный таймер, серия и сохраняемый кадр не прерываются автоотключением. После завершения съёмки отсчёт минуты начинается заново. Возврат в приложение часов сбрасывает отсчёт; после завершившейся сессии приложение автоматически запрашивает новую при открытии. При потере связи без сообщения об уходе в фон отсутствие часов определяется по пропущенным сигналам присутствия (до 8 секунд), затем отсчитывается минута. Порядок сообщений защищает от запоздалого сигнала закрытия после возврата.

Эта минутная политика применяется к сессии, которой уже управляли часы, даже если приложение телефона осталось открыто после автозапуска. Самостоятельная сессия, запущенная только на телефоне, сохраняет прежний тайм-аут 15 минут вне экрана телефона. Передача файлов и очередь автосохранения работают отдельно и не отменяются вместе с камерой.

## Фон, файлы и камера

«Параметры камеры → Работа в фоне» по умолчанию включено: видео и таймер одиночной съёмки продолжаются после выхода с часов. Если выключено, таймер отменяется, видео сохраняется и останавливается. Серия по удержанию останавливается всегда. «Отключить соединение» на любом устройстве завершает сессию независимо от фона. Автокопирование завершённых файлов — отдельная настройка.

По умолчанию: `DCIM/Camera`, `IMG_YYYYMMDD_HHMMSS.jpg` / `VID_YYYYMMDD_HHMMSS.mp4`, JPEG и MP4 H.264. На часах в «Файлы и сохранение → На телефоне», на телефоне в «Сохранение файлов» меняются папка, шаблон имени, JPEG/PNG/WebP и H.264/HEVC/VP8 при наличии кодировщика. При совпадении имён добавляется суффикс. PNG/WebP получаются из JPEG камеры, не являются RAW. Для звука WebM нужен Vorbis.

Выбирается максимальная площадь кадра, затем наибольший FPS при этом размере. Для высокого FPS при меньшем размере выберите режим вручную. `HR`/`MAX` — дополнительные таблицы разрешений, `HS` — высокоскоростная сессия. Доступны режимы, открытые прошивкой через Camera2; рекламные максимумы штатной камеры могут быть закрыты для сторонних приложений. Несовместимый максимальный размер фото заменяется следующим с сообщением. `snapshotMode: preview` означает снимок из потока пониженного качества во время видео.

Физическая пара Infinix X678B + Galaxy Watch Ultra не подключена к среде сборки. После обновления проверьте фото со знаком, видео 5–10 с, удаление и автосохранение. При сбое отправьте диагностику из приложения телефона с выбранным режимом и включённой сессией.

Опубликованные APK сохранили прежний сертификат. Из публичных исходников закрытый ключ исключён; параметры самостоятельной подписи описаны в BUILD.md.

## Скачивание: прогресс и отмена (1.7)

При нажатии «Скачать на часы» или «Скачать выбранные» появляется «Скачивание началось». Передача продолжится после закрытия галереи или приложения. Разрешите уведомления на часах: они показывают имя файла, номер в очереди, подготовку или процент передачи и кнопку «Отменить скачивание». Даже при запрете уведомлений статус остаётся в галерее.

В списке и плитке рядом с файлом видны «В очереди», «Подготовка скачивания…», процент или результат. В карточке файла есть отдельная кнопка отмены. Она отменяет очередь, к которой относится файл: готовые копии сохраняются, незавершённая удаляется. Автосохранение использует такой же статус и уведомление; отмена текущего автоматического файла не выключает настройку будущего автосохранения. Повторная передача готового файла с теми же параметрами не создаёт дубликат.

Процент вычисляется по размеру копии **после сжатия**. Подготовка на телефоне показывает неопределённый индикатор — её процент заранее неизвестен. После ошибки можно повторить скачивание.

## Звук записи и прослушивание (1.7)

В «Параметры камеры» два независимых переключателя:

- **Записывать звук микрофона / Record microphone audio** — микрофон телефона в сохранённом видео. По умолчанию включён.
- **Слушать микрофон телефона / Listen to phone microphone** — передача звука на часы при живом предпросмотре. По умолчанию выключена. Громкость регулируется громкостью мультимедиа часов.

Во время записи справа сверху вместо смены камеры отображается микрофон. Нажатие включает или выключает звук в текущем ролике, без остановки и без создания нового файла. Это работает и на паузе; после завершения записи возвращается смена камеры. Перечёркнутый микрофон означает тишину в ролике. Выбор сохраняется для следующих записей и не меняет настройку прослушивания.

Нужно разрешение микрофона **на телефоне**. Если его нет, нажмите «Разрешить микрофон на телефоне». Android может потребовать разблокировку и подтверждение. Если запись началась без разрешения, включить звук можно только в следующем ролике: добавить отсутствующую звуковую дорожку в уже начатый файл нельзя. Когда разрешение есть, даже запись с выключенным микрофоном содержит дорожку тишины, чтобы звук можно было вернуть. Общий захват микрофона остаётся активен, а отключённая запись получает нулевые аудиосэмплы; системное отключение микрофона не используется.

Выход из приложения часов прекращает прослушивание; запись в фоне продолжает действовать по настройке «Работа в фоне». Для прослушивания лучше использовать наушники: рядом с телефоном звук динамика часов может вернуться в микрофон. Это поток для мониторинга с задержкой, зависящей от связи, а не гарантированно синхронный звук предпросмотра. Записанный ролик использует общий таймер аудио и видео с исключением пауз. Просмотр ранее сохранённого видео в галерее использует его собственную звуковую дорожку.

Для MP4 используется AAC, 48 кГц, моно, целевой битрейт 128 кбит/с. Для WebM нужен доступный на телефоне кодировщик Vorbis. Прослушивание передаётся отдельно: 16 кГц, моно, ADPCM около 64 кбит/с. Звуки затвора и других действий часов настраиваются отдельно и не управляют микрофоном телефона.

Физические Infinix X678B и Galaxy Watch Ultra в этой среде недоступны. После установки проверьте короткий ролик: звук → выключение микрофона → пауза → включение → продолжение → остановка, затем прослушайте сохранённый файл. Поведение аппаратного кодировщика, реальная задержка и стабильность связи требуют этой проверки.
