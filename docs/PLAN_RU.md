# План проекта и состояние 0.2.0

| Этап | Результат | Состояние |
|---|---|---|
| Базовая камера и Wear-связь | Photo/video/pause/stop, таймеры, параметры, foreground service | Реализовано в 0.1, сохранено |
| Круглый интерфейс | Full-screen preview, curved HUD, quick icons, Material You, gray round icon | Реализовано в 0.2 |
| Серия удержанием | Lease, release/cancel, предел времени/числа, защита от reordered start | Реализовано; unit-тесты прошли |
| Галерея и оригиналы | Индекс, миниатюры, видео, open/delete/download, SHA-256 | Реализовано; транспорт unit-тестирован |
| Запуск телефона с часов | Ticket + RemoteActivityHelper + видимая Activity | Реализовано; проверка пары устройств впереди |
| Файлы | Папка, шаблоны, типы, сохранение настроек, коллизии | Реализовано |
| Высокие режимы | Расширенные таблицы Camera2, all codecs, normal/high-speed sessions, диагностика | Реализовано; доступность конкретного Infinix требует проверки |
| Сборка и статическая проверка | Два подписанных debug APK; 20 JVM-тестов; Lint | Пройдено |
| Приёмка на Infinix + Galaxy Watch | См. TEST_PLAN_RU.md, новые cameraApi-диагностические данные | Не выполнено: устройства не подключены |
| Дальнейший выпуск | Исправления по результатам приёмки, измерение FPS/нагрева, production signing и Play release при отдельном запросе | После приёмки |

Следующий шаг владельца устройств — обновить оба APK, запустить сессию, выполнить базовую проверку и экспортировать диагностику с cameraApi. Это позволит отделить ограничения прошивки от ошибки настройки сессии.
