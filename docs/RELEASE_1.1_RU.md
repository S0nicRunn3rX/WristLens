# WristLens 1.1.0 — изменения и проверка

24 октября 2026. Release, `debuggable=false`, `com.daniil.wristlens`, versionCode 1100 (телефон), 1101 (часы). Подпись прежняя для обновления поверх личной установки.

Реализованы обновление галереи после удаления, сохранение страницы настроек и прокрутки, автоматическая очередь оригиналов на часы, список/плитка, выбор до 50 файлов и системная отправка, английская/русская локализация, прозрачное время по дуге. Серия — до 50 кадров, по умолчанию 50 и 250 мс после сохранения кадра.

Фото со знаком проходят EXIF-ориентацию, рисование текста в пикселях и кодирование. Видео использует единый шейдер смешивания camera External OES и текстуры текста перед MediaRecorder. Журнал завершения публикаций предотвращает пропуск длинного видео; общий журнал копий предотвращает дубликаты ручной и автоматической передачи.

## Проверки

63 JUnit/Robolectric-теста: core 28, phone 10, wear 25. Они проверяют протокол, серию, файл SHA-256, политику съёмки, поведение настроек/галереи/доступности/локализации, размеры и касания круглого интерфейса, журнал публикаций и восстановление копий. XML и сводка находятся в `verification-1.1.0`.

Сохранённые JPEG/PNG/WebP проверены по пикселям: 3 формата × 4 угла × 2 цвета. JPEG без знака байт-в-байт совпадает с исходным. Дополнительно выполнены 32 GPU-проверки точного GLSL приложения с Android-текстурами: 4 поворота × 4 угла × 2 цвета, а также предпросмотр без знака. Хост Mesa llvmpipe. Отчёт — `gpu-report.json`.

Lint: 0 ошибок; телефон без замечаний, часы с одним предупреждением о более новой версии WorkManager. Используется зафиксированная 2.10.5.

```sh
./gradlew clean :phone:assembleRelease :wear:assembleRelease :core:test :phone:testReleaseUnitTest :wear:testReleaseUnitTest :phone:lintRelease :wear:lintRelease
python3 tools/test_gpu_watermark.py
```

Чистая сборка исключает наблюдавшийся сбой инкрементального DEX-кэша при изменении общих ресурсов. Финальные APK проверяются `apksigner verify`. Версии, сертификат и SHA-256 — в `verification-1.1.0/artifacts.json`.

## Ограничения

Физическая пара Infinix X678B + Galaxy Watch Ultra 2025 не подключена. Проверки не заменяют Camera2/HAL/MediaRecorder, фактическую связь/батарею и аппаратные жесты на устройствах.

Прямой стандартный Samsung «Двойной щипок» остаётся неподтверждённым. Исправлена регистрация общего Wear API и добавлено доступное действие для Samsung Universal Gestures («Выбрать» на центральной кнопке). Этот отдельный путь также требует проверки на часах. Недоступность общего API больше не трактуется как отсутствие жеста у модели.

Знак недоступен в HS. Максимальные разрешения/FPS зависят от публичных возможностей камеры и кодировщика. Очередь может откладываться Android, прерванный файл передаётся заново. Автосохранение выключено по умолчанию, переносит новые завершённые файлы, ограничено 4 ГБ на файл.

Фото со знаком требуют дополнительной памяти и перекодирования; видео — GPU-композиции. Проверка шейдера подтверждает пиксели и геометрию, но не аппаратный кодировщик Infinix. Перед важной съёмкой проверьте короткие фото и видео.
