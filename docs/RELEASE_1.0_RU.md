# WristLens 1.0.0 — отчёт release-сборки

23.10.2026. Выпущены два подписанных APK для установки поверх предыдущей личной версии; обновить нужно оба устройства.

## Результат

Верхняя дуга часов теперь содержит только текст с мягкой тенью. В меню и остальных круглых диалогах есть живые часы; пустая миниатюра не занимает место. Добавлены настройки фоновой съёмки и водяного знака, инструкция, состояние системного жеста и отключение сессии с обеих сторон. Пункт отмены серии/таймера из меню часов удалён; отмена активного таймера остаётся на центральной кнопке.

При открытии часов выполняется HELLO и, если камера не ответила, один автоматический запрос запуска телефона. Используются одноразовые билеты от сопряжённого ближайшего телефона. После явного отключения повторный запуск блокируется до следующего открытия приложения либо нажатия кнопки телефона. Порядок сообщений видимости проверяется по идентификатору Activity и счётчику: запоздалый onPause не завершает новую сессию.

Фон включён по умолчанию. При выходе с часов или потере соединения видео и одиночные фото-/видеотаймеры продолжаются. При выключенном фоне таймеры отменяются, видео завершается. Удерживаемая серия всегда прекращается. Явное отключение завершает всю сессию независимо от фона.

Водяной знак формируется системным шрифтом в маленькую текстуру и накладывается GLES перед подачей кадров в MediaRecorder. Положение учитывает зафиксированную ориентацию видео. Видеопоток не проходит через JPEG часов: JPEG-превью кодируется отдельно, без накопления очереди. При паузе/остановке передача кадров кодировщику синхронно прекращается. HS с водяным знаком отклоняется явно; обычное разрешение/FPS не понижается молча. Ошибка GPU останавливает запись с сообщением.

Системный ACTION_PRIMARY подключается только при доступности публичного Wear SDK API и функции производителя. Жест обрабатывается только при фокусе главного окна, с защитой от устаревших и повторных событий. Основное действие: фото, старт видео, стоп видео. При отсутствии поддержки меню сообщает ограничение, остальные функции работают.

## Границы проверки

Физические Infinix X678B и Galaxy Watch Ultra не подключены. Нативная отрисовка текста проверена; захват Camera2 → EGL → MediaRecorder, синхронизация аудио, FPS/нагрев/батарея, пауза на конкретном кодировщике, автоматический запуск в XOS и физический жест на Samsung не проверялись на устройстве. Надпись на сохранённом видео и её качество следует проверить тестовым роликом на телефоне. Автоматические тесты не эмулируют успешную аппаратную запись.

Жест зависит от публичной поддержки Wear SDK 36.1+ в прошивке. Автозапуск не обходит запросы разрешений, блокировку и ограничения Android. Фоновая работа не переживает принудительную остановку/перезагрузку. Водяной знак не поддерживает constrained high-speed (HS); это ограничение реализации, а не утверждение о невозможности в платформе.
