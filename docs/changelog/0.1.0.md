# WristLens 0.1.0

Debug · Initial camera remote / Первый пульт камеры

## English

- Initial paired Android/Wear OS camera remote with live preview, photo/video controls, timers, flash, focus and zoom.
- Command deduplication, frame limits, focus-coordinate mapping and permission checks.
- Both debug APK signatures and package identity verified; hardware and visual acceptance had not been performed.

Archived automated checks: **7 tests**. [Original report](../previous-0.1/VERIFICATION_RU.md).

## Русский

- Первая связка Android/Wear OS: живой поток, управление фото и видео, таймеры, вспышка, фокус и зум.
- Защита от повторных команд, ограничения кадров потока, преобразование координат фокуса и проверки разрешений.
- Проверены подписи и идентификаторы debug APK; аппаратная и визуальная приёмка ещё не проводилась.

Архивная автоматическая проверка: **7 тестов**. [Исходный отчёт](../previous-0.1/VERIFICATION_RU.md).
