# WristLens 1.1.0

Release · Reliable gallery and saved watermark / Галерея и знак в файлах

## English

- Refresh gallery after deletion and preserve settings page/scroll while changing values.
- Automatic original-copy queue, list/grid, multiple selection and system sharing.
- English default and Russian localization; curved transparent menu time.
- Watermark baked into saved photos/video; EXIF-aware photo processing and combined video shader.
- Burst default/limit raised to 50 frames with a 250 ms post-save interval at this version.

Archived automated checks: **63 tests**. [Original report](../RELEASE_1.1_RU.md).

## Русский

- Галерея обновляется после удаления; изменение параметров сохраняет страницу и прокрутку.
- Добавлены автоматическая очередь оригиналов, список/плитка, множественный выбор и системная отправка.
- Английский по умолчанию, русская локализация, прозрачное время по дуге.
- Знак встраивается в сохранённые фото/видео; обработка EXIF и общий видеошейдер.
- Лимит и значение серии — 50 кадров; в этой версии интервал после сохранения 250 мс.

Архивная автоматическая проверка: **63 тестов**. [Исходный отчёт](../RELEASE_1.1_RU.md).
