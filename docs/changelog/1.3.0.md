# WristLens 1.3.0

Release · Navigation, select all and bezel / Навигация, выбор всех и безель

## English

- Full gallery count and Select all across pages; stable indexing during deletion.
- Back closes one submenu level; confirmed settings display Saved.
- Remove rectangular scroll clipping, centre headings, add spacing and suppress overlapping state text.
- Long-press flash/timer/camera opens its settings; rotary and touch-bezel scrolling plus precise sliders.
- Persist three independent preview profiles; add a simpler experimental gesture mode (removed in 1.4.0).

Archived automated checks: **100 tests**. [Original report](../RELEASE_1.3_RU.md).

## Русский

- Точный счётчик галереи и «Выделить всё» для всех страниц; устойчивый индекс при удалении.
- Назад закрывает один уровень; подтверждённые параметры показывают «Сохранено».
- Убраны прямоугольные границы прокрутки, центрированы заголовки, добавлены интервалы, устранены наложения статусов.
- Удержание вспышки/таймера/камеры открывает настройки; добавлены безель, круговая сенсорная зона и точные слайдеры.
- Сохраняются три профиля предпросмотра; упрощённый экспериментальный жест впоследствии удалён в 1.4.0.
