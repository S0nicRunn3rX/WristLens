# WristLens 1.0.0

Release · Background capture and watermark / Фон и водяной знак

## English

- First release builds with debugging disabled; transparent status arc, clock in menus and in-app instructions.
- Automatic phone launch/session request, explicit disconnect and ordered watch presence messages.
- Configurable background video/timers; hold bursts stop on exit.
- Video date/time watermark composed through GLES; constrained high-speed watermark rejected explicitly.
- Optional platform primary gesture support was conditional on firmware; later versions replaced and then removed it.

Archived automated checks: **44 tests**. [Original report](../RELEASE_1.0_RU.md).

## Русский

- Первые release APK с выключенной отладкой: прозрачная строка по дуге, время в меню и инструкция.
- Автоматический запрос запуска телефона/сессии, отключение и защита от устаревших сообщений активности часов.
- Настраиваемые фоновые видео и таймеры; удерживаемая серия останавливается при выходе.
- Водяной знак даты/времени через GLES; режим HS со знаком явно отклоняется.
- Системный основной жест зависел от поддержки прошивки; позднее заменён, затем удалён.

Архивная автоматическая проверка: **44 тестов**. [Исходный отчёт](../RELEASE_1.0_RU.md).
