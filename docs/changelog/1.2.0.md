# WristLens 1.2.0

Release · Gallery layout and experimental gesture / Галерея и экспериментальный жест

## English

- Round menus use an inscribed scroll area and wrapped text, including nested settings and confirmation dialogs.
- List rows use a small thumbnail with filename/properties; grid uses two larger thumbnail columns.
- Show media type, date, size, available dimensions and duration.
- Experimental app-owned accelerometer/gyroscope double-pinch recognition with personal training and a test mode.
- This experimental gesture was not hardware-validated and was removed in 1.4.0.

Archived automated checks: **85 tests**. [Original report](../RELEASE_1.2_RU.md).

## Русский

- Для круглых меню добавлены вписанная область прокрутки и переносы текста, включая вложенные настройки и подтверждения.
- В списке — небольшая миниатюра и имя/свойства справа; в плитке — две колонки крупных превью.
- Показываются тип, дата, размер, доступное разрешение и длительность.
- Добавлен экспериментальный собственный детектор двойного щипка по акселерометру/гироскопу, обучение и тестовый режим.
- Точность на физических часах не подтверждена; функция удалена в 1.4.0.

Архивная автоматическая проверка: **85 тестов**. [Исходный отчёт](../RELEASE_1.2_RU.md).
