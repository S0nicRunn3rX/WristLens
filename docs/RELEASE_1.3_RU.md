# WristLens 1.3.0 — изменения и проверка

- Галерея: точный счётчик записей приложения; «Выделить всё» получает лёгкий индекс всех страниц. Снимок последовательности публикаций исключает новые файлы, появившиеся после начала выборки. Курсор rowid устойчив к удалению ранее просмотренных строк. Отмена выбора делает запоздалый ответ неактуальным. Удаление выбранного выполняется порциями по 50; отправка — до 500 файлов за одну операцию.
- Навигация: родительские диалоги не уничтожаются при входе в дочерние, в том числе при выборе разрешения из пропорций. Кнопка, системный Back и свайп с левого края закрывают один уровень. Асинхронная загрузка не открывает страницу после закрытия родителя.
- Сохранение: «Сохранено» после подтверждения настройки; ошибка не вызывает успешное уведомление. Локальные настройки также подтверждаются.
- Интерфейс: убрано прямоугольное окно и горизонтальные границы обрезки. Прокрутка на всю площадь с отступами содержимого. Заголовки центрированы, между элементами — интервалы. Прозрачные часы скрываются при прокрутке, чтобы не накладываться на текст. У пустого превью нет второй конкурирующей надписи состояния; старое уведомление очищается при новой сессии.
- Ввод: удержание вспышки, таймера и смены камеры открывает нужный пункт. Rotary input и собственная сенсорная зона по краю поддерживают меню и шаги слайдера около 0,05. Справа рисуется дуга позиции. Системный rotary-ввод зависит от часов; сенсорная зона не требует аппаратного безеля.
- Предпросмотр: профили 320 px/JPEG40/330 мс, экран/JPEG60/67 мс, экран/JPEG85/125 мс. Описание и целевые верхние FPS показаны в интерфейсе. Профиль сохраняется. Параметры обычных фото и видеокодировщика не меняются; snapshot из превью зависит от этого профиля.
- Жест: простой режим без обучения с тремя чувствительностями, отдельно от личных шаблонов. Обе реализации собственные. Готовые альтернативы рассмотрены в GESTURE_OPTIONS_RU.md.

## Проверка

Итоговые результаты, JUnit XML, Lint и нативные отрисовки находятся в `verification-1.3.0`. Добавлены проверки полного экрана при 384/416/480 px и шрифте 100/150/200%, rotary и сенсорного края, точного шага зума, возврата на предыдущий уровень, успешного/неуспешного уведомления, быстрых пунктов, выбора всех 105 файлов при загруженных 20, удаления тремя порциями, отмены запоздалой выборки, устойчивого индекса при удалении, пресетов качества и простого жеста без профиля. Ранее существовавшие тесты сохранения, водяного знака, фонового копирования и личного детектора сохранены.

Нативные отрисовки используют системный шрифт; фирменный рукописный шрифт пользователя отсутствует в среде. На физической паре Infinix X678B + Galaxy Watch Ultra 2025 проверка не выполнена. Простой жест остаётся экспериментальным: тесты проверяют сигналы и программные условия, а не точность распознавания человека.

APK: release, `debuggable=false`, package `com.daniil.wristlens`, versionCode 1300/1301. Сертификат прежний для обновления поверх установленной версии. Открытый ключ разработки не является защищённым production-ключом. Публикация в Google Play не выполнялась.

Для стандартного вращательного ввода использованы рекомендации [Android Rotary input](https://developer.android.com/training/wearables/compose/rotary-input). Собственная реализация выполнена на Views с обработкой SOURCE_ROTARY_ENCODER / AXIS_SCROLL; Compose в приложение не добавлялся.
