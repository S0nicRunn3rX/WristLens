# Проверки WristLens 0.2.0

## Автоматические

`./gradlew :core:test :phone:assembleDebug :wear:assembleDebug :phone:lintDebug :wear:lintDebug`

20 JVM-тестов: 7 исходных тестов framing, границ, геометрии фокуса, ориентации, журнала повторов и неверного zoom; 13 новых — release до start, пропажа release, число/длительность серии, длинный таймер, чужой hold-ID, поворот и предел пикселей, запрет увеличения, побайтовая передача нескольких блоков, повреждение SHA-256, нехватка места, обрыв и имена файлов.

Результаты конкретной сборки — в VERIFICATION_RU.md и docs/verification. Тесты core не заменяют проверку камеры/MediaStore/Data Layer/EGL.

## Приёмка на физических устройствах — пока не выполнена

| № | Сценарий | Ожидаемый результат |
|---|---|---|
| 1 | Обновление поверх 0.1 обоих APK | Установка без удаления; приложение связывается |
| 2 | Запуск с часов при выключенной сессии | PhoneActivity открывается, после разрешений камера стартует; блокировка требует пользователя |
| 3 | Фото задней/передней камеры | Правильные ориентация, имя, папка, содержимое файла |
| 4 | Удержание: отпускание, уход за кнопку, Home, Bluetooth off | Новые кадры прекращаются; уже начатый может завершиться |
| 5 | Удержание дольше лимита, лимиты 3/30, таймер 60 с | Не больше лимита; время серии считается после таймера; отпускание отменяет таймер |
| 6 | Видео 30 с с паузой, продолжением, снимком и стопом | Корректный файл; пауза не добавляет длительность; snapshotMode явно показывает fallback |
| 7 | Меню и быстрые кнопки на круглом экране | Все значки доступны, не обрезаны; тап фокуса соответствует изображению |
| 8 | Вспышка обеих камер, auto/on/torch/off | Только доступные режимы; экранный свет выключается при скрытии окна |
| 9 | MAX/HR фото и 60/HS видео, если доступны | Реальный размер/частота по файлу; отказ отображён; можно выбрать другой режим |
| 10 | PNG/WebP/MP4 AVC/HEVC/WebM | Файл декодируется; кодек и расширение соответствуют; WebM audio ограничен Vorbis |
| 11 | DCIM/Camera, своя подпапка, SAF, отзыв разрешения | Выбранный путь работает; отзыв вызывает понятную ошибку, без молчаливой смены папки |
| 12 | Две фотографии в одну секунду | Нет перезаписи; суффикс коллизии; четыре шаблона дают ожидаемые имена |
| 13 | Галерея, >20 файлов, удаление, открытие на телефоне | Корректная пагинация/действия; чужие файлы не отображаются |
| 14 | Оригиналы JPEG/PNG/WebP/video, мало места, обрыв, уход с экрана | SHA-256 совпадает; неполный файл не появляется; повторная загрузка доступна |
| 15 | Копия на часах без телефона, HEVC без декодера | Своя галерея доступна; неподдерживаемый видеокодек даёт сообщение |
| 16 | Поворот телефона/зеркало фронтальной камеры/60 FPS | Превью и точка фокуса согласованы, размеры отправки не выше дисплея |
| 17 | Слабый Bluetooth, Wi-Fi, 10 минут записи, нагрев | Поток не накапливает очередь; запись управляется; измерить фактический FPS и батарею |

Для проверки оригиналов сравнить SHA-256 файлов на двух устройствах. Для видео проверять реальное число кадров/длительность, а не только метаданные. Для 108 Мп сравнить JPEG dimensions и cameraApi; не считать интерполированный файл доказательством аппаратного режима.
