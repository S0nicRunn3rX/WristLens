# WristLens

Управляйте **камерой Android-телефона с часов Wear OS** и смотрите живой поток на запястье. WristLens состоит из приложений для телефона и часов и использует доступные сторонним приложениям возможности камеры. Проект создавался для Infinix X678B и Samsung Galaxy Watch Ultra 2025; телефон Samsung или Pixel не требуется.

## Возможности

| Съёмка и камера | Интерфейс часов |
|---|---|
| Фото, видео, пауза/продолжение и фото во время видео | Живое изображение на весь круглый экран |
| Серия до 50 кадров при удержании кнопки | Щипок для подгонки изображения, сдвиг и сброс двойным касанием |
| Раздельные таймеры фото/видео; вспышка и фонарь | Быстрые иконки; удержание открывает нужные настройки |
| Передняя/задняя камера; фокус, точка экспозамера, зум | Прокрутка безелем и точная регулировка слайдеров |
| Доступные разрешение, пропорции, FPS и кодеки | Галерея списком/плиткой, счётчик, выбор нескольких файлов и отправка |
| Дата/время как водяной знак на фото и видео | Оригинальные или сжатые копии, автосохранение, прогресс скачивания |
| Раздельные запись звука и прослушивание микрофона | Настраиваемые вибрация, звуки съёмки и анимация затвора |

## Установка и подключение

1. Скачайте **оба** APK из [релиза 1.8.0](https://github.com/S0nicRunn3rX/WristLens/releases/tag/v1.8.0): `WristLens-phone-1.8.0-release.apk` и `WristLens-wear-1.8.0-release.apk`.
2. Установите телефонную часть на Android **10+**, часовую — на Wear OS с Android API **30+**. Устройства должны быть сопряжены и иметь Google Play services. Без телефона приложение часов не снимает.
3. Один раз откройте приложение телефона и выдайте разрешение камеры; для звука нужен микрофон. Затем открывайте WristLens на часах: оно автоматически запрашивает запуск приложения телефона и сессии. Android может потребовать разблокировку или подтверждение разрешения.
4. Обновляйте оба устройства вместе. Опубликованные APK сохраняют прежнюю подпись проекта. [Установка через ADB, управление и устранение проблем](docs/INSTALL_RU.md).

По умолчанию интерфейс английский. При основном системном языке ru используется русский; язык каждого устройства выбирается независимо.

## Основные действия

| Действие | Управление |
|---|---|
| Сделать фото / начать видео | Центральная кнопка в выбранном режиме |
| Серия | Удерживать кнопку фото; отпустить для остановки |
| Пауза / продолжение видео | Нижняя левая кнопка при записи |
| Остановить видео | Нижняя правая кнопка при записи |
| Фото во время видео | Центральная кнопка во время записи |
| Выключить / включить звук в текущем ролике | Верхняя правая кнопка микрофона; работает и на паузе |
| Фокус / экспозамер | Касание изображения, если камера поддерживает |
| Изменить зум камеры | Безель / вращательный ввод или параметры камеры |
| Вписать, увеличить, сдвинуть изображение на часах | Щипок / перетаскивание; двойное касание для сброса |

**Подгонка предпросмотра не меняет зум камеры.** При вписывании в круг появляются чёрные поля; сохранённые файлы не меняются. Распознавание щипка в воздухе удалено в 1.4.0. Жесты 1.8.0 выполняются пальцами на экране.

## Значения по умолчанию

- Оригиналы: `DCIM/Camera`, `IMG_YYYYMMDD_HHMMSS.jpg` / `VID_YYYYMMDD_HHMMSS.mp4`. Папка, шаблон имени и доступные типы файлов настраиваются.
- Камера: максимальная доступная площадь кадра, затем наибольший FPS для этого размера. Режим с меньшим разрешением и большим FPS выбирается вручную.
- Серия: **50 кадров**, **200 мс после сохранения предыдущего**, общий предел 60 секунд. Экспозиция и обработка добавляют время.
- Запись звука включена; прослушивание выключено. Работа в фоне включена; автокопирование на часы выключено. Копии по умолчанию сохраняются в исходном качестве в `DCIM/Camera`.
- Через минуту фонового простоя часов сессия камеры отключается. Запись, пауза, таймеры и сохраняемый кадр защищены. Очереди передачи работают независимо.

## Сборка

Java 17 · Android SDK 36 · Gradle wrapper · Android Gradle Plugin 8.13.2.

```sh
chmod +x gradlew
./gradlew :phone:assembleDebug :wear:assembleDebug
./gradlew :core:test :phone:testDebugUnitTest :wear:testDebugUnitTest
```

Модули: `core` — протокол и правила, `shared` — общий интерфейс и обмен, `phone` — камера и медиа, `wear` — часы, галерея и скачивания.

В публичных исходниках нет закрытого ключа подписи. Debug использует локальный стандартный ключ; для подписанного release задайте собственные одинаковые параметры для двух приложений. [Сборка и подпись](docs/BUILD.md). Исторические APK не изменены. Самостоятельная сборка с другим сертификатом не установится поверх них.

## История и проверка

[Архив версий](RELEASES.md) охватывает debug **0.1.0 → 0.2.0 → 0.2.1 только для часов** и release **1.0.0–1.8.0**. Есть [общий changelog](CHANGELOG_RU.md), отдельная двуязычная запись для каждой версии и исходные отчёты. Наличие старых APK и снимков исходников отдельно указано в архиве.

В исходном отчёте 1.8.0 зафиксированы **179 успешных JUnit/Robolectric-тестов** и **0 ошибок Android Lint**; оставшиеся предупреждения перечислены. Это сохранённый результат предыдущей сборки, а не новая аппаратная проверка публичного экспорта. [Полный отчёт 1.8.0](docs/RELEASE_1.8_RU.md).

Возможности камеры зависят от открытых Camera2/HAL и кодировщика телефона. Рекламное разрешение сенсора и FPS могут быть недоступны сторонним приложениям. Частота предпросмотра зависит от связи. Водяной знак не поддерживается в constrained high-speed; некоторые фото при видео снимаются из предпросмотра с меньшим качеством. Реальную камеру, связь и ограничения оболочки нужно проверять на устройствах.

## Данные и лицензия

Команды, поток и файлы передаются через Wear OS Data Layer между сопряжёнными устройствами. Камера и микрофон требуют разрешений телефона. Медиа остаются на устройствах, пока вы сами не выберете отправку. Перед публикацией диагностики проверьте её содержимое.
